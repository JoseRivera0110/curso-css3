MEDIDAS EN CSS

Las unidades en CSS determinan el tamaño de elementos, textos, márgenes y paddings. Se clasifican en absolutas (fijas) y relativas (adaptables).

MEDIDAS ABSOLUTAS

Es el tipo de medidas las cuales siempre se mantendran fijas, indiferentemente del tamaño donde se visualice. Como ejemplo esta el pixel (px), se va a adaptar a la cantidad de pixeles que se coloquen, y si estan sobrepasa el tamaño es posible que se cree un scroll

MEDIDAS RELATIVAS

Son aquellas medidas las cuales pueden variar de acuerdo al contexto donde se encuentre, son un tipo de medidas muy empleado para lograr el efecto responsive. Suelen adaptarse a el tamaño del viewport de donde se pueda visualizar.

REM y EM

  • La diferencia central entre rem y em está en cuál es su punto de referencia (de dónde heredan el tamaño):
    • rem (Root EM): Toma como referencia el tamaño de fuente del elemento raíz (<html>).
    • em: Toma como referencia el tamaño de fuente de su propio elemento o de su padre directo.
  1. rem (Root EM)

    Por defecto en los navegadores, <html> tiene un tamaño de 16 px.

    • 1 rem = 16 px
    • 1.5 rem = 24 px
    • 2 rem = 32 px
  2. em:

    Calcula el valor multiplicando la fuente del padre (para el font-size) o del propio elemento (para padding, margin, width, etc.).

    Efecto Cascada / Multiplicativo: Si anidas varios elementos usando em en su font-size, los tamaños se van multiplicando exponencialmente.

EJEMPLO PRACTICO

Boton con medidas REM Boton con medidas EM 
 
                        
                                .link-1{                                                    .link-2{
                                    font-size: 2rem;                                            font-size: 2rem;
                                    padding: 1rem 2rem;                                         padding: 1em 2em;
                                    border-radius: 0.5rem;                                      border-radius: 0.5em;
                                    border: .2rem solid #333;                                   border: .2em solid #333;
                                }                                                           }

Como se puede observar, ambos botones poseen el mismo digito de rem y em en cada propiedad, sin embargo, debido a que su toma de referencia del tamaño de la fuente es diferente, influye en el tamaño de el modelo de caja y de su contenido.

Para el REM siempre su valor sera el referenciado al HTML (por defecto 16px), que podrian variar si se cambia manualmente. Mientras en el caso del EM el tamaño de la fuente varia segun la etiqueta, contenedor, body o html. En este caso puntual el font-size presente (2rem) modifica el valor de la fuente por defecto del HTML de 16px a 32px.

Para hacer una explicacion grafica, esto vendria a funcionar de la siguiente forma:

 
                        
            .link-1{                                                                        .link-2{
                font-size: [(16px) x 2] = 32px; <--(el REM mantendra los 16px del HTML)         font-size: [(16px) x 2] = 32px; <--(este es el nuevo EM)
                padding: [(16px) x 1] = 16px [(16px) x 2] = 32px;                               padding: [(32px) x 1] = 32px [(32px) x 2] = 64px;
                border-radius: [(16px) x 0.5] = 8px;                                            border-radius: [(32px) x 0.5] = 16px;
                border: [(16px) x 0.2] = 3.2px solid #333;                                      border: [(32px) x .2] = 6.4px solid #333;
            }                                                                               }
