STACKING CONTEXT

El Stacking Context (Contexto de Apilamiento) es el concepto de CSS que determina el orden en el que los elementos HTML se dibujan en la pantalla sobre el eje Z (profundidad: qué elemento queda al frente y cuál detrás).

El orden por defecto dibuja los elementos de fondo hacia adelante (fondo del cuerpo → bloques normales → elementos flotantes → elementos posicionados). Sin embargo, cuando se crea un stacking context, ese elemento se convierte en la "raíz" de un nuevo grupo aislado de capas para todos sus hijos.
